Data source
The same Google Apps Script connection reads the ledger and sends stock entries to your existing sheet. No spreadsheet migration is required.

Updated catalogue
Material names, suppliers and minimum thresholds come from the supplied “Dinaledi Inventory System (Updated)” workbook. The existing live feed supplies transactions, not master catalogue edits. If you later change material names or thresholds in the sheet, this embedded catalogue must also be updated.

Saved and live data
The workbook snapshot is available immediately. A successful refresh replaces it with the returned live ledger. If a feed appears incomplete, the last complete data remains visible. Confirmed data is cached on this device when browser storage is available.

Historical materials
Transactions for materials outside the new catalogue remain in the ledger and usage dashboard, but are not offered for new stock entries.

Submission status
The existing connection sends requests without a readable acknowledgement. An entry is marked confirmed only when a matching new transaction appears in the ledger. The app never automatically resends an entry.
